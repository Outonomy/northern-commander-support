# Northern Commander support

Public issue tracker for [Northern Commander](https://northerncommander.com), a free,
keyboard-first, dual-pane file manager for macOS in the text-mode DOS tradition, from
[Outonomy](https://outonomy.dev). The application's source isn't here — this repository is
only for support.

## Something wrong, or something you'd like to see?

**If you can still open the application**, use **Report a Problem…** or **Send Feedback…** —
in the application menu, the Options menu (`F9`), or `⌘K`. That's the way to reach us for
anything involving logs, file paths, or anything else personal: it goes privately, includes
logs only if you agree, and nothing you write is posted here as-is. When a report is worth
other people knowing about, we write it up in our own words as a new issue below.

**Otherwise, open an issue right here.** Please:

- **Search first** — [open](https://github.com/Outonomy/northern-commander-support/issues) and
  [closed](https://github.com/Outonomy/northern-commander-support/issues?q=is%3Aissue+is%3Aclosed).
  If one already covers it, add a comment or a 👍 instead of opening another.
- **Never paste logs, file paths, or anything personal into an issue or comment here — this
  repository is public.** Use Report a Problem for anything like that instead.

Feature ideas are also welcome in
[Discussions](https://github.com/Outonomy/northern-commander-support/discussions).

Prefer email? [support@northerncommander.com](mailto:support@northerncommander.com) reaches us
privately too.

## What happens next

We read every report and issue and, when something is worth tracking publicly, open or update an
issue here ourselves — in our own words, with nothing quoted from a private report. Replies and
write-ups here are posted as **Outonomy Support**. Once a fix ships, we comment on the issue
naming the version it shipped in.

See the [support page](https://northerncommander.com/support/) for the full walkthrough, and the
[privacy page](https://northerncommander.com/privacy/) for what a report sends and what we do with
it.
